# 宏观与事件栏目：交付与验证

## 放在哪里

顶栏新增 **宏观与事件**，地址 `/observatory`，位于“逐日历史”和“因子研究”之间。
栏目内分成“经济数据”“新闻事件”“因子走势”，避免把市场环境、交易账户和研究操作混在一起。

- 经济数据：美国和中国各 8 项。美国包括新增非农、失业率、CPI、核心 CPI、
  联邦基金有效利率、10 年国债收益率、实际 GDP、PCE；中国包括 CPI、PPI、
  制造业 PMI、非制造业商务活动、M2、GDP 累计同比，以及两个独立的年度长历史指标。
- 新闻事件：美联储公告、中新网财经、BBC 商业新闻；按地区、关键词、类型、
  最近 7/30 天或全部存档筛选。正文保留在原站，页面展示标题、发布时间、来源和链接。
- 因子走势：美国 Fama–French 五因子的月度收益及 12 个月滚动年化波动；
  本项目 3 个 LightGBM 预测周期和 2 个动量对照的逐日样本外 Rank IC，
  以及 21 个交易日 IC 标准差。

曲线支持 5/10/50 年或全部历史；下面可展开逐期数据表，翻页和下载 CSV。
每条序列都显示单位、频率、所属期、真实覆盖、来源和抓取时间。

## 计算和时间口径

- 非农：季调就业总量相邻月份差值；CPI/PCE 同比使用同口径指数相隔 12 个月的比值。
  先补齐统计日历中的空缺，再差分，禁止跨缺月计算。
- “较上期”只使用相邻统计期；上期缺失就留空，不跳到更早的有效值。
- 因子收益使用百分数单位。波动率为完整 12 个月样本标准差乘 `sqrt(12)`，
  先在全历史上计算，再截取用户选择的窗口。
- 本地 IC 为同一交易日预测值与已成熟远期收益的横截面 Spearman 相关，
  至少 5 个共同有效标的；21 日 IC 波动不年化，也不称为策略收益率。
- 宏观数据使用当前修订值，所属期不是首次发布日期。尚未接入一致预期、发布时点
  vintage 数据和完整经济日历，因此没有“超预期”评分，也不能将这些当前修订值直接用于历史时点交易。
- 新闻风险标签是标题关键词线索，可能漏报或误报；不构成已核实事件结论。
  日期缺失不伪造发布时间，未来日期不显示为已发生新闻，内容不直接触发交易。

## 运行和复核

本机已有 launchd 常驻后端，观察线程随拥有 broker 的 API 服务启动，
不在注入测试 broker 的应用实例中自动启动。历史模拟的独立常驻任务保持运行。
观察代码不改交易规则、历史账本或模型参数。

- 宏观和因子每 6 小时检查；新闻每 15 分钟检查；状态心跳每分钟更新。
- 默认缓存 `~/.quantit/observatory`；原始内容在 `raw/`，各序列在 `series/`，
  `news.json` 保存最新 5,000 条已采集新闻。API 对单次新闻查询最多返回最新 300 条，
  页面显示截断提示，可缩小筛选范围。
- 单源失败保留之前成功结果和时间，页面显示异常；缓存更新时间和观测截止期独立判断。
- `QUANTIT_OBSERVATORY=0` 关闭采集；`QUANTIT_OBSERVATORY_ROOT` 修改缓存目录；
  `QUANTIT_OBSERVATORY_EXPERIMENT` 指向真实冻结实验。
- 电脑关机、睡眠或无网络期间无法采集；恢复后由常驻服务继续检查。

```bash
.venv/bin/python -m pytest -q
cd web && npm run build
curl http://127.0.0.1:8000/api/health

curl 'http://127.0.0.1:8000/api/v1/observatory/news?region=CN&days=7'
```
