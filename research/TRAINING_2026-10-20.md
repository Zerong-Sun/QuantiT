# Alpha158 模型策略实施与六方面验证（2026-10-20）

## 已实施

- 复用官方 Qlib Alpha158 特征代码，在本地数据上训练 LightGBM，不把网上的配置参数当作可盈利的预训练权重。
- 新增 1、5、10 日预测模型，以及 20、60 日动量规则对照，共五个独立研究策略。各自保存参数、预测、模型和净值，不改写六个现有策略账户。
- 加入按日可用性延迟、训练/验证/最终留出期、标签清除、五日隔离、三个扩展训练窗口、交易成本和双倍成本压力检验。
- 先选持仓数、调仓频率、换手上限，再比较两组树模型参数。全部参数只由验证集选择，测试期不参与调参。
- 新增只读 API 与前端研究结果表；代码和完整复现命令见 `closeloop/README.md`。

## 实际数据与结果

使用 2020-01-02 至 2026-10-20 的 1,645 个市场交易日、236 只股票。验证期始于 2024-01-25；最终样本外信号期为 2025-06-12 至 2026-10-19，328 个交易日，末次收益使用 2026-10-20 的收盘。特征统一延迟一个市场交易日，日线收盘成交仅为研究代理。

| 策略 | 样本外扣费累计收益 | 最大回撤 | 夏普 | 日均 Rank IC | 双倍成本收益 | 统计门槛 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| Alpha158 · LightGBM 1 日 | 3.95% | -19.53% | 0.258 | 0.0269 | -4.95% | 未通过 |
| Alpha158 · LightGBM 5 日 | 10.59% | -14.08% | 0.467 | 0.0289 | 0.86% | 未通过 |
| Alpha158 · LightGBM 10 日 | 19.57% | -15.98% | 0.701 | 0.0282 | 9.20% | 统计通过 |
| 20 日动量对照 | 114.00% | -43.15% | 1.553 | -0.0044 | 96.77% | 未通过 |
| 60 日动量对照 | 87.44% | -41.70% | 1.383 | 0.0053 | 77.41% | 未通过 |

同期同股票池月度等权对照收益 **18.60%**，最大回撤 **13.56%**。它不是官方沪深 300 指数，且含一个持仓缺价估值日，因此差距较小的超额收益尤其需要谨慎复核。以上均为累计历史模拟收益，不是实盘业绩或年化收益。

10 日模型比等权对照高约 0.97 个百分点，回撤更大；这只支持继续研究，不能证明稳健优势。1 日模型双倍成本后亏损，5 日模型未跑赢对照，说明换手成本与市场共同上涨会掩盖预测信号的实际价值。动量对照的高收益伴随超过 40% 的回撤，不符合当前预设风险门槛。

本次使用日横截面 Rank IC，不能与此前四因子模型的 pooled IC 直接比较。独立策略也不等于彼此不相关；完整日收益相关矩阵保存在同目录 JSON 中。

**统计通过不等于允许自动交易。** 五个新策略均保持独立影子评估：固定股票池缺少历史成分变化，复权数据缺少逐时点快照，分数持仓和近似日线成交尚未覆盖整手、最低佣金及完整执行约束。这些限制已写入报告和 API，未通过修改阈值来强行上线。

## 六方面验证与修复清单

| 方面 | 原有缺口 | 本次实现与验证 |
| --- | --- | --- |
| 需求完整性 | 只有单次 IC 训练，缺少完整策略实验 | 三种模型周期、两种规则对照、参数选择、独立曲线、最新模型及前端展示全部落地 |
| 逻辑正确性 | pooled IC 无法说明扣费收益；同日特征可用性没有落实 | 按市场日延迟、日均 Rank IC、自融资现金与费用、从初始净值计算回撤；独立重放五条曲线全部一致 |
| 边界情况 | 缺价、停牌、零成交量、标签末尾和训练边界容易被误用 | 缺价估值明确标记；缺价/零量/极端涨跌不成交；最后一天不虚构未来收益；每折标签成熟并隔离后才进入训练 |
| 代码质量 | 训练、参数搜索与展示需要清晰隔离 | 分离 evaluation、portfolio、experiment、verify_experiment；不导入交易模块；API 只读文本报告，不加载模型文件 |
| 测试覆盖 | 缺少成本、可用性、未来数据隔离和新 API 回归 | 新增 20 个研究测试及 3 个 API 测试；全量离线 **481 passed，1 skipped，1 deselected** |
| 实际运行 | 缺少可复核模型与前端实测 | 在独立 Python 3.11 环境完成真实训练；1,416 个 Qlib 行情文件与面板一致；模型/预测/曲线有校验和；生产构建通过 |

额外核验：模型训练数据不受未来特征或标签修改影响；验证选参不受后续评分修改影响；API 即使收到报告中的开启交易字段也始终返回研究模式。前端研究表展示所有五个策略，不只展示表现最好的模型。

桌面浏览器实际展示了五个策略的收益、回撤和门槛；展开 10 日模型可见数据/执行限制与三个窗口收益。390px 手机视口下页面宽度仍为 390px，表格在卡片内横向查看，无整页溢出。报告缺失、损坏和结构不完整均有明确状态；最后一次 API 防御性校验修改后，15 项 API 测试再次通过。

## 保存位置与运行边界

完整本机产物：`~/.quantit/closeloop/experiments/alpha158-2026-10-20-v1/`。包括 `manifest.json`、`features.parquet`、每折及最新 LightGBM 文本模型、预测、CSV 净值、`report.json` 和 `verification.json`。摘要数值保存在 `research/TRAINING_2026-10-20.json`。

训练环境为 Python 3.11.16、Qlib 0.9.7、LightGBM 4.7.0；原服务继续使用现有 Python 3.9 环境。后台两个 worker 均运行，重启前后成交总数保持 1,492。本次训练没有下单，新策略未纳入交易调度；前端定时读取完成的研究报告，不会偷偷重复训练。

在最终留出期结果已知后，不应继续对该区间调参并声称它仍是未见样本。下一轮需要新的时间段、历史时点股票池与更完整执行验证；不能承诺通过微调获得盈利。
