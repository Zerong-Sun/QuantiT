# 资本资产定价模型 (CAPM)

## 1. 标准 CAPM

### 基本假设
1. 投资者是理性的，追求均值-方差最优
2. 同质预期：所有投资者对资产收益有相同预期
3. 无摩擦市场：无交易成本、无税收、资产无限可分
4. 无风险借贷利率相同
5. 所有投资者在同一投资期限内

### 证券市场线（SML）
$$E[R_i] = R_f + \beta_i (E[R_m] - R_f)$$

其中：
- $R_f$：无风险利率
- $E[R_m]$：市场组合期望收益率
- $\beta_i = \frac{\text{Cov}(R_i, R_m)}{\text{Var}(R_m)}$：系统性风险
- $E[R_m] - R_f$：市场风险溢价

### Beta 的含义
- $\beta = 1$：与市场同步波动
- $\beta > 1$：比市场波动更大（进攻型）
- $\beta < 1$：比市场波动更小（防御型）
- $\beta < 0$：与市场反向波动（对冲）

## 2. CAPM 的实证检验

### 经典检验
**Black, Jensen & Scholes (1972)**：
- 对 NYSE 股票进行时间序列回归
- 发现 SML 比理论预测的更平坦

**Fama & MacBeth (1973)**：
- 横截面回归检验
- Beta 与收益率的关系弱于 CAPM 预测

### CAPM 的问题

| 问题 | 描述 |
|------|------|
| 规模效应 | 小公司收益率高于 CAPM 预测 |
| 价值效应 | 高 B/M 公司收益率高于 CAPM 预测 |
| 动量效应 | 过去赢家继续赢，输家继续输 |
| 低波动异象 | 低波动股票风险调整后收益更高 |
| 流动性溢价 | 低流动性股票有额外收益 |

## 3. 估计 Beta

### OLS 回归
$$R_{i,t} - R_{f,t} = \alpha_i + \beta_i (R_{m,t} - R_{f,t}) + \epsilon_{i,t}$$

**样本期选择**：
- 5 年月度数据（60 个月）
- 2-3 年周度数据
- 60-120 个交易日日度数据

### 指数加权
给近期数据更高权重：
$$\hat{\beta}_{EW} = \frac{\sum_{t=1}^T \lambda^{T-t} (R_{m,t} - \bar{R}_m)(R_{i,t} - \bar{R}_i)}{\sum_{t=1}^T \lambda^{T-t} (R_{m,t} - \bar{R}_m)^2}$$

其中 $\lambda \in (0.94, 0.97)$ 是衰减因子。

### Bayesian 估计
收缩估计，将个体 Beta 向截面均值收缩：
$$\hat{\beta}_{Bayes} = \delta \bar{\beta} + (1-\delta) \hat{\beta}_{OLS}$$

**优点**：减少估计误差，提高样本外预测能力。

## 4. 扩展 CAPM

### 零 Beta CAPM (Black)
$E[R_i] = E[R_z] + \beta_i (E[R_m] - E[R_z])$

其中 $R_z$ 是零 Beta 组合的收益率。无需无风险资产假设。

### CAPM-X（条件 CAPM）
$$E_t[R_{i,t+1}] = R_{f,t+1} + \beta_{i,t} \lambda_t$$

Beta 和风险溢价都随时间变化，与宏观经济状态相关。

### 消费 CAPM (CCAPM)
$$E[R_i] = R_f + \beta_{i,mc} (E[R_m] - R_f)$$

其中 $\beta_{i,mc} = \frac{\text{Cov}(R_i, MC_t)}{\text{Var}(MC_t)}$，$MC_t$ 是边际消费替代率。

## 5. 实际应用

### 作为基准
- CAPM 提供了简单的风险调整基准
- Alpha = 实际收益 - CAPM 预测收益

### 项目折现率
$$WACC = E\% \times R_e + D\% \times R_d (1-T)$$
其中 $R_e = R_f + \beta_e (R_m - R_f)$

### 组合构建
- Beta 中性组合：$\sum w_i \beta_i = 0$
- 市场中性策略：对冲市场风险

## 6. 局限性

| 局限 | 说明 |
|------|------|
| 单因子 | 只考虑市场风险，忽略其他系统性风险 |
| 静态模型 | 假设 Beta 恒定，实际随时间变化 |
| 市场组合不可观测 | 真正的市场组合包含所有可投资资产 |
| 实证支持弱 | 规模、价值等异象无法解释 |
| 短期无效 | 短期 Alpha 可能为正，长期趋近于零 |
