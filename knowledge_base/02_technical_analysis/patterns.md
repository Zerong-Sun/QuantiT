# K线形态与图表形态

## 1. K线基础

### 单根K线结构
```
      ┃  上影线
  ┌───┤
  │   │  实体
  └───┤
      ┃  下影线
```

- **实体**：开盘价与收盘价之间
- **上影线**：最高价与实体顶部
- **下影线**：最低价与实体底部

### K线颜色
- 阳线（上涨）：收盘 > 开盘（通常为绿色/白色）
- 阴线（下跌）：收盘 < 开盘（通常为红色/黑色）

## 2. 反转形态

### 锤子线/上吊线（Hammer）
**形态**：小实体在顶部，长下影线（≥ 实体 2 倍），无或短上影线

**锤子线**（底部反转）：
- 出现在下跌趋势末端
- 表示空方打压后多方反击
- 次日阳线确认

**上吊线**（顶部反转）：
- 出现在上涨趋势末端
- 需要次日阴线确认

### 吞没形态（Engulfing）
**看涨吞没**：
- 下跌趋势中出现阴线
- 次日阳线完全包住前一日阴线
- 成交量放大更可靠

**看空吞没**：
- 上涨趋势中出现阳线
- 次日阴线完全包住前一日阳线

### 十字星（Doji）
**形态**：开盘价 ≈ 收盘价

**类型**：
| 类型 | 形态 | 含义 |
|------|------|------|
| 标准十字星 | 上下影线等长 | 犹豫不决 |
| 长脚十字星 | 长上下影线 | 多空激烈争夺 |
| 墓碑十字星 | 无下影线 | 上方压力大 |
| 蜻蜓十字星 | 无上影线 | 下方支撑强 |

### 早晨之星/黄昏之星

**早晨之星**（三根K线，底部反转）：
1. 长阴线
2. 小实体（星线），向下跳空
3. 长阳线，收盘进入第一根阴线实体

**黄昏之星**（三根K线，顶部反转）：
1. 长阳线
2. 小实体（星线），向上跳空
3. 长阴线，收盘进入第一根阳线实体

### 三只乌鸦/红三兵

**三只乌鸦**（顶部反转）：
- 连续三根长阴线
- 每日收盘价创新低
- 每日开盘价在前一日实体内

**红三兵**（底部反转）：
- 连续三根长阳线
- 每日收盘价创新高
- 每日开盘价在前一日实体内

## 3. 持续形态

### 旗形（Flag）
**形态**：急剧运动后出现平行四边形整理

**牛旗**：
- 上涨后的向下倾斜整理
- 成交量萎缩
- 突破后延续上涨

**熊旗**：
- 下跌后的向上倾斜整理
- 成交量萎缩
- 突破后延续下跌

### 三角形

**对称三角形**：
- 高点降低，低点升高
- 成交量递减
- 方向不确定，等待突破

**上升三角形**：
- 高点持平，低点升高
- 上方阻力，下方支撑抬高
- 看涨信号

**下降三角形**：
- 低点持平，高点降低
- 下方支撑，上方压力降低
- 看跌信号

### 楔形（Wedge）
**上升楔形**：
- 两条上升但收敛的趋势线
- 通常在顶部出现
- 看跌信号

**下降楔形**：
- 两条下降但收敛的趋势线
- 通常在底部出现
- 看涨信号

### 矩形（Rectangle）
**形态**：价格在水平支撑和阻力之间震荡

**交易策略**：
- 区间交易：在支撑买入，阻力卖出
- 突破交易：等待突破后跟进
- 量度目标：突破点 ± 矩形高度

## 4. 缺口（Gap）

| 类型 | 形态 | 含义 |
|------|------|------|
| 普通缺口 | 区间内小缺口 | 通常回补 |
| 突破缺口 | 区域突破时 | 不回补，趋势信号 |
| 持续缺口 | 趋势中间 | 趋势加速 |
| 衰竭缺口 | 趋势末端 | 可能回补，反转信号 |

### Island Reversal（孤岛反转）
- 衰竭缺口 + 突破缺口
- 形成孤立的价格区域
- 强烈反转信号

## 5. 形态量化

### 支撑/阻力识别算法
```python
def find_support_resistance(prices, window=20):
    support = []
    resistance = []
    for i in range(window, len(prices) - window):
        if prices[i] == min(prices[i-window:i+window+1]):
            support.append((i, prices[i]))
        if prices[i] == max(prices[i-window:i+window+1]):
            resistance.append((i, prices[i]))
    return support, resistance
```

### 形态可靠性评估
- **时间跨度**：形态持续时间越长越可靠
- **成交量确认**：突破时成交量放大
- **幅度**：形态幅度越大，突破后目标越远
- **测试次数**：多次测试支撑/阻力越可靠

## 6. 形态交易的统计视角

| 形态 | 典型胜率 | 盈亏比 | 期望值 |
|------|----------|--------|--------|
| 头肩顶 | 65% | 2.5:1 | +0.875 |
| 双底 | 60% | 2:1 | +0.4 |
| 旗形 | 70% | 1.5:1 | +0.55 |
| 三角形 | 55% | 2:1 | +0.2 |

**期望值 = 胜率 × 盈亏比 - (1-胜率)**
