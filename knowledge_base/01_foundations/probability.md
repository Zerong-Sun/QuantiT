# 概率论与随机过程

## 1. 概率空间

**定义**：概率空间是一个三元组 $(\Omega, \mathcal{F}, P)$

- $\Omega$：样本空间，所有可能结果的集合
- $\mathcal{F}$：事件域（σ-代数），可测事件的集合
- $P$：概率测度，满足 $P(\Omega) = 1$

**直觉**：在量化交易中，$\Omega$ 代表所有可能的市场状态，$\mathcal{F}$ 是我们能观察到的信息集，$P$ 是对未来的概率判断。

## 2. 随机变量与分布

### 常用分布

| 分布 | 用途 | 密度函数 |
|------|------|----------|
| 正态分布 $N(\mu, \sigma^2)$ | 收益率建模基础 | $f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ |
| 对数正态分布 | 价格过程 | $f(x) = \frac{1}{x\sigma\sqrt{2\pi}} e^{-\frac{(\ln x-\mu)^2}{2\sigma^2}}$ |
| t 分布 | 厚尾收益率 | 自由度参数 $\nu$ |
| 稳定分布 | 极端事件建模 | 特征指数 $\alpha \in (0, 2]$ |

### 收益率分布的经验事实

1. **尖峰肥尾**：相比正态分布，实际收益率分布有更高的峰度和更肥的尾部
2. **波动率聚集**：高波动后往往跟随高波动（GARCH 效应）
3. **非对称性**：负收益的波动通常大于正收益（杠杆效应）

## 3. 重要收敛概念

### 几乎处处收敛（a.s.）
$$P(\lim_{n \to \infty} X_n = X) = 1$$

### 依概率收敛
$$\forall \varepsilon > 0: \lim_{n \to \infty} P(|X_n - X| > \varepsilon) = 0$$

### 依分布收敛（弱收敛）
$$\lim_{n \to \infty} F_{X_n}(x) = F_X(x)$$

**交易含义**：大数定律保证了长期频率趋近概率；中心极限定理是 VaR 等风险度量的理论基础。

## 4. 条件期望

$$E[X | \mathcal{F}_t] = \text{在信息集 } \mathcal{F}_t \text{ 下 } X \text{ 的最佳预测}$$

**核心性质**：
- **鞅性质**：$E[S_T | \mathcal{F}_t] = S_t$（无套利条件）
- **塔性质**：$E[E[X|\mathcal{G}]|\mathcal{F}] = E[X|\mathcal{F}]$（$\mathcal{F} \subseteq \mathcal{G}$）
- **投影解释**：条件期望是 $L^2$ 空间中到子空间的正交投影

## 5. 鞅论

### 定义
随机过程 $(M_t)_{t \geq 0}$ 是鞅，如果：
1. $E[|M_t|] < \infty$
2. $E[M_t | \mathcal{F}_s] = M_s$，对所有 $s \leq t$

### 鞅的分类

| 类型 | 定义 | 金融含义 |
|------|------|----------|
| 上鞅 | $E[M_t | \mathcal{F}_s] \leq M_s$ | 有系统性亏损的策略 |
| 下鞅 | $E[M_t | \mathcal{F}_s] \geq M_s$ | 有系统性盈利的策略 |
| 鞅 | $E[M_t | \mathcal{F}_s] = M_s$ | 公平游戏/无套利价格 |

### 鞅表示定理
任何鞅都可以表示为随机积分：
$$M_t = M_0 + \int_0^t \sigma_s dW_s$$

这是 Black-Scholes 期权定价的理论基础。

## 6. 布朗运动（Wiener 过程）

**定义**：标准布朗运动 $(W_t)_{t \geq 0}$ 满足：
1. $W_0 = 0$
2. 独立增量
3. $W_t - W_s \sim N(0, t-s)$，$s < t$
4. 路径连续

**几何布朗运动**（股票价格模型）：
$$dS_t = \mu S_t dt + \sigma S_t dW_t$$

解：
$$S_t = S_0 \exp\left[\left(\mu - \frac{\sigma^2}{2}\right)t + \sigma W_t\right]$$

## 7. Poisson 过程与跳跃

**泊松过程** $(N_t)_{t \geq 0}$，强度 $\lambda$：
$$P(N_t = k) = \frac{(\lambda t)^k}{k!} e^{-\lambda t}$$

**复合泊松过程**（跳跃扩散模型）：
$$dS_t = \mu S_t dt + \sigma S_t dW_t + S_{t^-} J dN_t$$

其中 $J$ 是跳跃幅度随机变量。Merton 跳跃扩散模型使用此框架。

## 8. 量化交易中的应用

| 理论工具 | 交易应用 |
|----------|----------|
| 条件期望 | 预测收益率、信号生成 |
| 鞅 | 期权定价、无套利检验 |
| 布朗运动 | 连续时间资产定价、Greeks 计算 |
| Poisson 过程 | 尾部风险建模、极端事件 |
| 大数定律 | 回测有效性验证 |
| 中心极限定理 | 投资组合风险估计 |
