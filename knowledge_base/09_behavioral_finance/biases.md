# 认知偏差

## 1. 过度自信偏差
- 高估自己的知识和预测能力
- 过度交易，收益更低

## 2. 损失厌恶

### 前景理论
$$V(x) = \begin{cases} x^\alpha & x \geq 0 \\ -\lambda(-x)^\beta & x < 0 \end{cases}$$

其中 $\lambda \approx 2.25$（损失厌恶系数）

### 处置效应
- 过早卖出赢家（锁定利润）
- 过久持有输家（避免实现损失）

## 3. 锚定效应
投资者过度依赖初始信息（锚点）
- 支撑/阻力位的心理作用
- 整数关口的影响力

## 4. 代表性启发
- **外推偏差**：认为近期趋势会持续
- **热手谬误**：认为连胜会继续
- **赌徒谬误**：认为连输后必赢

## 5. 羊群效应
投资者跟随他人行为，导致泡沫和恐慌性抛售

## 6. 确认偏差
寻找支持自己观点的信息，忽略相反证据

## 7. 利用认知偏差

| 偏差 | 策略 |
|------|------|
| 处置效应 | 买入输家，卖出赢家 |
| 锚定效应 | 逆向投资 |
| 羊群效应 | 动量策略 |
| 过度反应 | 长期反转策略 |
